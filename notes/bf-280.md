- **Security validation** prevents unauthorized file access and corruption
- **Robust resume** survives browser crashes and interruptions
- **Air-gap support** with QR code display for delta codes

### Architecture Decisions

**Chose block-granular delta** (not rolling-hash) because:
- Maintains D15 (L fixed) and D19 (K derived) invariants
- Compatible with existing fountain code system
- Sufficient for software distribution (component-aligned changes)
- 99.76% savings for typical updates

### Usage

**Receiver generates delta code:**
```typescript
const result = await generateDeltaCode(newFile, oldFile);
console.log(result.deltaCode); // SFD-1A2B3C4D-5E6F7A8B-1-3,7-9A-2
```

**Sender processes delta code:**
```typescript
await enterDeltaMode(context, deltaCode, newFile);
await confirmDeltaMode(context, oldFile, true);
// Transfer only differing blocks
```
