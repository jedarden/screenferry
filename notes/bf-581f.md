## Architecture

The caching system uses a three-layer approach:

1. **Device Fingerprinting** (`createDeviceSignature()`)
   - userAgent, platform, hardwareConcurrency, deviceMemory
   - Hashed to create consistent cache key

2. **IndexedDB Storage** (`cacheBenchmarkResult()`)
   - Database: `screenferry-ge-benchmark`
   - Store: `results`
   - Key: Composite signature hash

3. **Cache Retrieval with TTL** (`loadCachedBenchmarkResult()`)
   - Checks version match
   - **NEW:** Checks timestamp against 30-day TTL
   - Returns null if expired, triggering fresh benchmark

## Technical Details

### TTL Calculation
```typescript
const age = Date.now() - data.result.timestamp;
if (age > CACHE_TTL_MS) {
  console.log(`Cached benchmark result expired (age: ${Math.round(age / 1000 / 60 / 60 / 24)} days)`);
  resolve(null); // Cache expired
}
```

### Expiry Handling
- Exact TTL boundary (30 days) is treated as expired
- Cache age is logged in days for user visibility
- Expired cache triggers automatic re-benchmark in `getKMaxWithFallback()`
